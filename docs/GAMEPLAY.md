# 游戏玩法

## 基本流程

1. 选择角色和模式，开始新游戏
2. 进入第 1 层，你有 4 次出牌和 4 次换牌
3. 从手牌中选择 1-5 张牌打出，获得分数
4. 分数达到目标分即过关，进入商店
5. 在商店用金币购买小丑牌和消耗品
6. 继续下一层，直到通关九层塔或输光

## 界面布局

游戏采用三栏布局：

```
┌─────────┬───────────────────────┬──────────┐
│ 左侧栏  │      中间卡牌区       │ 右侧栏   │
│         │                       │          │
│ 关卡信息 │  小丑位 (6格)         │ 牌堆     │
│ Boss    │  消耗品位 (2格)       │          │
│ 分数    │                       │ 上一手   │
│ 牌型预览 │  手牌区               │          │
│         │                       │          │
│ 资源    │  出牌 / 换牌按钮      │          │
│ 菜单按钮 │                       │          │
└─────────┴───────────────────────┴──────────┘
```

## 计分规则

最终得分 = (牌型底分 + 计分牌点数总和) × 倍率

### 牌型底分和倍率

| 牌型 | 底分 | 倍率 | 说明 |
|------|------|------|------|
| 高牌 | 5 | 1 | 不成任何牌型，取最大的一张 |
| 一对 | 10 | 2 | 两张相同点数 |
| 两对 | 20 | 2 | 两组不同的对子 |
| 三条 | 30 | 3 | 三张相同点数 |
| 顺子 | 35 | 4 | 五张连续点数 |
| 同花 | 40 | 4 | 五张相同花色 |
| 葫芦 | 50 | 5 | 三条 + 一对 |
| 四条 | 70 | 7 | 四张相同点数 |
| 同花顺 | 120 | 10 | 五张连续点数且同花 |
| 皇家同花顺 | 160 | 12 | 10 J Q K A 同花顺 |
| 五条 | 220 | 18 | 五张相同点数（需要特殊效果） |

### 计分牌点数

- A = 11
- 2-10 = 面值
- J / Q / K = 10

只有参与牌型构成的牌才计入计分牌点数。

### 小丑加成

小丑牌会在计分时产生额外效果，分为五类：

| 类型 | 说明 |
|------|------|
| 底分型 | 增加底分数值（chips） |
| 加倍率型 | 增加倍率数值（mult） |
| 乘倍率型 | 将最终倍率乘以某个倍数（xmult） |
| 功能型 | 特殊机制（购买奖励、回合奖励等） |
| 临时型 | 一次性效果，使用后消失 |

小丑效果按顺序叠加：先加所有底分，再加所有倍率，最后乘所有乘倍率。

## 角色

| 角色 | 初始小丑 | 解锁条件 |
|------|---------|---------|
| 普通人 🧑 | 无 | 默认 |
| 顺子牌手 🃏 | 捷径（顺子跳1点） | 通关困难九层塔 |
| 同花牌手 🌸 | 模糊（红方同花/黑梅同花） | 困难模式单局 50000 分 |

## 游戏模式

| 模式 | 特点 | 解锁条件 |
|------|------|---------|
| 简单模式 🌱 | 1次复活，低目标分，不计成就 | 默认 |
| 困难模式 🔥 | 无复活，高目标分，计入成就 | 默认 |
| 无尽模式 ♾️ | 无限层数，目标分指数增长 | 通关九层塔 |

## Boss

每 3 层一个 Boss（第 3、6、9 层），Boss 带有减益效果：

### 弱 Boss（第 3 层）
- **封王**：人头牌（J/Q/K）不计分，不触发人头相关小丑
- **镣铐**：手牌上限 -1
- **强迫症**：必须打出 5 张才计分
- **断色**：随机一种花色不计分

### 中 Boss（第 6 层）
- **唯一**：第一次计分的牌型被锁定，之后只有该牌型正常计分
- **不许重复**：每种牌型只能计分 1 次
- **沉默**：随机 1 张永久小丑本层失效
- **点名**：每次出牌前随机指定 1 张手牌，必须打出或弃掉

### 强 Boss（第 9 层）
- **高墙**：目标分提高 50%
- **针眼**：只能出牌 1 次
- **无弃牌**：换牌次数变为 0
- **封锁**：随机禁用一种牌型

## 商店

每层过关后进入商店：
- 4 个商品（2 张小丑 + 2 张消耗品，随机刷新）
- 可以卖出已有的小丑和消耗品（半价回收）
- 可以花费金币刷新商品
- 最多持有 6 张小丑和 2 张消耗品

## 操作技巧

- 优先凑高牌型（顺子、同花以上），倍率提升最大
- 前期购买便宜的普通小丑积累经济，后期买高稀有度小丑爆发
- 星球牌升级常用牌型（如顺子、同花）收益很高
- 塔罗牌可以在关键时刻救场，把烂牌变成有用的牌
- Boss 关要提前规划，针对减益调整策略
